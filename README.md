# Canva-showcase

Varnita's Gallery

It is a modern, dark-themed digital archive and portfolio designed to organize, showcase, and interact with my Canva design projects in one central place. Built with a focus on visual storytelling, it features an aspect-ratio-preserving masonry grid, real-time search, instant category filtering, and an interactive project lightbox with direct "Edit in Canva" links. Designed for zero-maintenance hosting on GitHub Pages, the entire catalog runs dynamically from a clean, database-free JavaScript data layer—allowing seamless portfolio updates simply by adding new design entries directly to the code.
